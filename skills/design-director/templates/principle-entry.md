# Maintainer principle-entry template

## <short reusable principle>

**Trigger.** When this decision matters.

**Action.** What the agent should actually do.

**Evidence level.** Observed in product / validated external evidence / heuristic / hypothesis.

**Calibration.** Exceptions, thresholds that must not become universal laws, and context that changes the decision.

**Verification.** What evidence would show the action worked and what guardrail could reveal harm.

**Provenance.** Source URL/name/date and any license/attribution constraints. This field is for maintainers; do not copy restricted source prose into MIT runtime material without compatible permission.
