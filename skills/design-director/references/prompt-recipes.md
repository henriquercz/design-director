# Prompt recipes

Users do not need mode names. These are optional examples.

## Autonomous improvement
`$design-director Improve this interface to a professional product-quality bar. Inspect what exists, identify the real root causes, choose the smallest useful treatment sequence, preserve functionality, and verify desktop + mobile before finishing.`

## Audit only
`$design-director review this interface. Do not edit anything. Prioritize the highest-impact problems and map each to the correct treatment.`

## De-slop
`$design-director This page feels generic and AI-generated. Make it feel authored and specific to the product without flattening it into bland minimalism.`

## Product hardening
`$design-director Harden this dashboard for real daily use: realistic data, states, density, keyboard/touch, responsive behavior, errors, loading, and edge cases. Preserve the working flows.`

## Brand voice
`$design-director Sharpen the art direction of this landing page so the brand is recognizable from the page itself. Build around the product's real proof, not generic SaaS decoration.`

## Narrow scope
`$design-director Fix only the mobile composition of this component. Desktop identity, type, and color are already approved.`

## Full redesign
`$design-director Redesign this surface end-to-end while preserving product behavior and content obligations. Change the spatial premise, visual system, and interaction character, then verify the result.`

## Tokenization
`$design-director The visual decisions are approved. Consolidate the repeated values and component patterns into semantic tokens/primitives without changing the rendered design.`
